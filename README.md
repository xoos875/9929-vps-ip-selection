## 低延迟到底由什么决定

由线路和距离决定，与服务器配置关系不大。

物理距离划出下限。香港机房到大陆通常能压到30ms以内，美西洛杉矶普遍在150–180ms之间——这是光速和路由路径决定的，任何商家都绕不过去。线路质量决定的是另一件事：晚高峰（20:00–23:00）你的延迟能不能维持住白天的水平。

中文圈常说的几条优化线路，对应关系如下：

| 线路 | 归属 | 特点 |
| --- | --- | --- |
| CN2 GIA（AS4809） | 电信精品网 | 双向直连，晚高峰几乎不降速，价格最高 |
| 9929（AS9929） | 联通精品网 | 联通用户体验接近CN2 GIA，价格低一档 |

优化线路和普通线路的差距，白天测速基本看不出来，一到晚高峰就见分晓：普通国际线路容易抖动、丢包率明显上升，CN2 GIA这类双向直连线路基本能稳住。所以判断一台机器是不是真低延迟，要在晚高峰时段拉长时间测，商家贴的测速图说明不了问题。

## 常见问题

**延迟多少算低延迟？**
看机房位置。香港通常在30ms以内，美西洛杉矶在150–180ms之间，这是物理距离决定的下限。线路优化的意义在于晚高峰也能贴近这个下限，而不是白天下限更低。

**为什么测速正常，晚上九点后还是卡？**
大概率是普通国际线路。优化线路和普通线路白天差距不大，20:00–23:00的晚高峰才是分水岭。验证方法很简单：连续几个晚上在高峰时段跑ping或mtr，看丢包率。

**原生IP、家宽IP和机房IP有什么区别？**
原生IP注册地与机房一致；家宽（住宅）IP来自ISP的家庭宽带地址段；机房IP属于数据中心地址段。前两类在流媒体解锁、AI服务风控和社媒注册上的通过率明显高于机房IP，这也是丽萨主机这两条产品线的主要卖点。

**年付十几美元的百元机能不能做低延迟业务？**
能买，但别指望低延迟。这类机器（如年付9.88–12.99美元的美西套餐）便宜在普通线路和大流量配额，面向海外访客的业务用它们没问题；对国内低延迟有硬需求，还是得走CN2 GIA、9929、CMIN2这类优化线路。
